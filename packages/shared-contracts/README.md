# The Harvest - Shared Contracts Package

## Overview
This package defines the canonical TypeScript types and JSON Schemas shared between
mobile clients (React Native / Android Jetpack Compose) and backend agent services.

## Contents
- `src/contracts.ts`: TypeScript strict-mode interfaces for all 8 agents and the Dashboard Spec
- `src/dashboard-spec.schema.json`: Formal JSON Schema for client-side and server-side validation
